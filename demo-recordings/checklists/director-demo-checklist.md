# Director Demo Checklist

## Before Recording

- [ ] Website builds.
- [ ] Admin dashboard builds.
- [ ] Mobile app runs on an iPhone simulator.
- [ ] No demo-only wording is visible on public pages.
- [ ] No broken images.
- [ ] No broken video player layout.
- [ ] No console, terminal, source code, or devtools visible.
- [ ] Demo data is safe and does not reveal private information.
- [ ] No secrets, tokens, database URLs, or passwords are visible.
- [ ] Prayer times look correct.
- [ ] Iqamah times show iqamah.ca/manual-update context correctly.
- [ ] Jumu'ah times look correct.
- [ ] Event cards look clean.
- [ ] Summer camp promotion is visible and respectful.
- [ ] Donate links work or clearly open the approved donation page.
- [ ] Contact links work.
- [ ] Media page works.
- [ ] Taraweeh clip area does not autoplay audio.
- [ ] Admin Publish Changes works or is shown in safe demo mode.
- [ ] Push notification preferences are visible if implemented.

## After Recording

- [ ] Videos play correctly.
- [ ] Audio is disabled unless intentionally needed.
- [ ] File sizes are reasonable for WhatsApp/private sharing.
- [ ] No private info is shown.
- [ ] Demo is not too long.
- [ ] Public website desktop demo is clear.
- [ ] Public website mobile demo is clear.
- [ ] Admin dashboard demo is controlled.
- [ ] iPhone app demo is smooth.
- [ ] Upload/share as a private link first.
