# Film typography

Montserrat by The Montserrat Project Authors, distributed under the included SIL Open Font License 1.1.

Source: https://github.com/google/fonts/tree/main/ofl/montserrat

These static Black (900) and Medium (500) instances were produced from the official variable typeface using fontTools. Their glyph subset covers the Latin caption characters used by the community film (Unicode U+0020–U+017E). The copyright and name metadata are retained. The fonts are editing assets; they add no native app dependency.
