# Android Widget Scaffold

Expo managed apps need native Android work for real home screen widgets. This folder now includes starter native files:

```text
widgets/android/HBICPrayerWidgetProvider.kt
widgets/android/res/layout/hbic_prayer_widget.xml
widgets/android/res/xml/hbic_prayer_widget_info.xml
```

Use them after the project is prebuilt and native Android folders are owned.

## Widget Data

Use the same compact widget snapshot as iOS, generated by `@hbic/shared`:

- next prayer
- next iqamah
- countdown
- Jumu'ah reminder
- Ramadan iftar/suhoor
- upcoming event

## Native Next Step

1. Run `npx expo prebuild`.
2. Add an Android App Widget provider.
3. Copy `HBICPrayerWidgetProvider.kt` into the Android app package.
4. Copy the XML files into the matching Android `res/layout` and `res/xml` folders.
5. Add the provider to `AndroidManifest.xml`.
6. Add the string resource `hbic_prayer_widget_description`.
7. Persist `widget_prayer_snapshot` in shared preferences.
8. Update the widget when the app receives new prayer/iqamah data or a push refresh.

Use large text, simple colors, and no clutter.
