# One Masjid Bilal app link

Share **https://hbic.ca/download**.

- iPhone/iPad/iPod browser hints redirect to the existing official Apple listing
  (app ID `6790937097`).
- Android browser hints redirect to the existing official Google Play listing
  (package `ca.hbic.calgary.app`).
- Other or unrecognized devices go to `/app`, which already offers both stores.
  A browser deliberately disguising its device may also receive this choice.

This is a temporary server redirect, without JavaScript, cookies, added tracking
or a third-party smart-link service. It uses only the ordinary User-Agent header.
Responses are dynamic and non-cacheable, varying by User-Agent so one phone's
destination is not reused for another. Destinations come from existing fixed
store configuration; query parameters cannot choose a target or reach the stores.
GET and HEAD are supported. Native app updates are not required.

`npm run test:app-download` checks seven groups: iOS/in-app browsers,
Android/tablets/in-app browsers, unknown/desktop/unsupported devices, cache
isolation, HEAD/query safety, real shared-card rendering, and deterministic QR
asset generation. The static 3.9-KB QR is generated by
`npx tsx apps/public-web/scripts/generate-app-download-qr.mts`; its decoded payload
was independently checked as the exact share link.

The same link and QR appear in the shared public-site footer, Home app promotion,
app landing/closing download areas, and the live prayer-display footer. Direct
store options remain on `/app` so desktop/unknown-device visitors can choose.
The TV now decodes one static image instead of two; prayer data, alerts, timers,
weather, social and contact features remain unchanged. The published QR-enabled
display setting was already on and was not modified. An already-open TV browser
must reload `/display` once to receive a new application layout; this deployment
does not remotely control or forcibly refresh the masjid's physical Fire TV.
