# HBIC design references

Masjid Bilal’s existing identity and layouts guide the work. Start with the user’s task, the current screen and the project’s product notes. Use Impeccable alongside the sources below. Pick examples that help solve the specific layout, interaction or content problem.

| Work | References | How to use them |
| --- | --- | --- |
| Apple platforms | [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/), [Duo guidance](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo), [Apple Design Resources](https://developer.apple.com/design/resources/), [SwiftSkills](https://swiftskills.dev/), [Cupertino](https://cupertino.design/) | Use Apple’s guidance for safe areas, reflow, native controls and accessibility. Check the relevant Swift or UIKit APIs in Apple’s documentation and verify on the correct simulator. |
| Shipped app flows | [Mobbin](https://mobbin.com/), [Refero](https://refero.design/), [Refero MCP](https://refero.design/mcp), [Refero Styles](https://styles.refero.design/) | Study a comparable reading, navigation or onboarding task. Carry forward the useful behavior and build it with HBIC’s own interface and assets. Refero’s MCP connection requires Pro. Use examples already available to the team. |
| Visual review and typography | [Impeccable](https://impeccable.style/), [Taste Skill](https://github.com/Leonxlnx/taste-skill), [Hallmark](https://github.com/Nutlope/hallmark), [UI Skills](https://www.ui-skills.com/), [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), [Unslop](https://github.com/heydamir/unslop), [Better Typography](https://github.com/jakubkrehel/skills/blob/main/skills/better-typography/SKILL.md), [Frontend Design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md), [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) | Review real rendered screens for hierarchy, legibility, alignment and purposeful spacing. Check Arabic, Dari and Urdu wrapping and type shaping alongside English. Keep titles descriptive and give each screen a clear primary action. |
| Motion and components | [Emil Kowalski’s AI for UI](https://aiforui.dev/skills), [21st.dev](https://21st.dev/), [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) | Use motion to explain a change or confirm an action. Respect Reduce Motion and avoid continuous effects on the Quran reader or TV display. Use the web references to assess component accessibility, load cost and maintainability. |
| Website and launch references | [Inspo](https://inspomcp.dev/), [Minimal Gallery](https://minimal.gallery/), [Awwwards](https://www.awwwards.com/), [Land-book](https://land-book.com/), [Landingfolio](https://www.landingfolio.com/), [SiteInspire](https://www.siteinspire.com/), [Recent](https://recent.design/), [Godly](https://godly.website/), [Landing Gallery](https://www.landing.gallery/) | Use these for page rhythm, editorial typography, app promotion and launch treatments. Recent also carries the former Godly archive. Pick references that still make prayer information and registration easy to find. |
| Finding specialist guidance and early concepts | [Skills.sh](https://skills.sh/), [My Open Tabs](https://www.myopentabs.design/), [UiChemy Design Skills](https://uichemy.com/design-skills/), [Imagegen Skills](https://github.com/Leonxlnx/imagegen-skills) | Find guidance for a specific design question and read the publisher’s source. Use sketches or image concepts when they help choose a new visual direction. Verify shipped screens with real captures and use approved assets and authentic footage for HBIC content. |

For a review, compare the existing and updated screens with real data at the sizes where people use them. Check the page or app in light and dark appearance where supported, with larger text and reduced motion where applicable. Include touch targets, safe areas, Arabic shaping, keyboard interaction and focus when relevant. For the Fire TV prayer display, use real device performance and legibility as the deciding evidence. Record what was checked and what was released.
