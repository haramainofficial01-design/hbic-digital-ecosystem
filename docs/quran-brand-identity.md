# Quran & Recite identity

An original sibling mark for the Quran experience, not a replacement for the
Masjid Bilal app icon, mosque logo or Academy identity. An open Mushaf sits
within a flowing navy enclosure with one gold accent and a teal binding.

Original artwork was developed using the image-generation skill and the
existing HBIC app/masjid marks as visual references. It is not a copied Tarteel
logo and is not described as human-authored. Production packaging preserves
transparency at 512 × 512 pixels; each platform asset is 131,002 bytes, with
matching SHA-256 hashes. The ivory badge keeps the navy silhouette legible on
both light and dark backgrounds. No new native dependency, animation, blur,
recognition initialization or downloaded reciter audio is introduced.

The mark is integrated into the mobile Quran home and home toolbar, dedicated
Mac Quran sidebar/home toolbar and public-web Quran heading. Functional
navigation icons remain functional; focused reading stays uncluttered.
Decorative images do not repeat adjacent headings to screen readers.

## Artwork direction

Original professionally art-directed Quran & Recite sibling HBIC emblem;
navy #082D42, teal #079CA8, warm gold #E8C875, ivory #FFF9EB. Open Mushaf with
balanced ivory pages and a central spine inside a flowing navy calligraphic
enclosure; restrained gold rising stroke and teal lower binding. Strong
small-size silhouette and negative space. No text, pseudo-Arabic, watermark,
copied Tarteel identity, photographic texture or decorative background.
Built-in image generation, transparent background, new original artwork.

## Verification and release status

- Actual native/web components rendered headlessly at 24, 32, 48 and 88 pixels;
  headings fit 320, 390 and 900 pixel light/dark layouts. PNGs decoded at their
  full 512-pixel source resolution with matching bytes and RGBA transparency.
- Actual Mac components passed 640, 900, 1280 and 1512 pixel light/dark layout
  and callback tests using explicitly disclosed native-view adapters.
- Public reader passed all 14 browser layout cases from 320–1920 pixels, including
  navigation through every Quran tool. Test content is browser-intercepted, not
  production content or a native simulator screenshot.
- Mobile/public-web typechecks, public-web build, mobile lint and both iOS and
  Android Hermes bundle exports passed. Existing build warnings remain.

No production deployment, OTA update, store build upload or review submission
is implied by these checks. Recitation recognition qualification remains separate.
